
# AI팩토리 - AI 콘텐츠 마켓플레이스 UX 구현 계획

## 브랜드 & 디자인
- 크몽과 유사한 밝고 깔끔한 화이트 베이스 디자인
- 포인트 컬러: 블루-퍼플 계열 (AI/테크 느낌 가미)
- 핵심 USP 강조: **반값 가격 | 높은 퀄리티 | 빠른 납기 | 대량생산**

## 서비스 카테고리 (7개)
1. **AI 이미지/디자인** — 로고, 배너, 상세페이지, 썸네일, 일러스트
2. **AI 영상/모션** — 숏폼, 제품영상, 모션그래픽, AI 아바타 영상
3. **AI 글/카피라이팅** — 블로그, SNS, 광고카피, 번역
4. **AI 음악/보이스** — 배경음악, TTS, 나레이션, 효과음
5. **AI 비서 구축 & 크레딧** — 챗봇, 자동화, API 연동
6. **AI 웹툰/미니게임** — AI 웹툰 제작, 미니게임 개발
7. **AI 광고 제작** — 퍼포먼스 광고, SNS 광고 소재

## 프론트엔드 페이지 (더미 데이터 기반 정적 UI)

### 1. 홈페이지 (`/`)
- 상단 네비게이션: 로고, 카테고리 메뉴, 검색바, 로그인/회원가입
- 히어로 섹션: "AI로 만드는 콘텐츠, 에이전시 반값에" + 검색바 + 인기 키워드 태그
- 카테고리 아이콘 그리드 (크몽 스타일)
- 인기 서비스 카드 캐러셀 (별점, 가격, 리뷰 수)
- USP 배너 (반값, 퀄리티, 납기, 대량생산 강조)
- 포트폴리오 갤러리 섹션
- 푸터

### 2. 카테고리/서비스 목록 (`/category/:id`)
- 사이드 필터 (가격대, 납기, 정렬)
- 서비스 카드 그리드 (이미지, 제목, 가격, 별점, 리뷰)
- 페이지네이션

### 3. 서비스 상세 (`/service/:id`)
- 서비스 이미지 갤러리
- 서비스 설명, 가격 패키지 (Basic/Standard/Premium 테이블)
- 포트폴리오 예시
- 리뷰 섹션
- "문의하기" 채팅 버튼 & "주문하기" CTA

### 4. 채팅 문의 (`/chat`)
- 채팅방 목록 (좌측)
- 메시지 영역 (우측) — 텍스트 + 파일 첨부
- 프로젝트 상태 표시

### 5. 주문/결제 (`/order`)
- 선택한 패키지 요약
- 요구사항 입력 폼
- 결제 정보 영역

### 6. 프로젝트 관리 — 고객용 (`/my-projects`)
- 진행중/완료 프로젝트 목록
- 프로젝트 상세: 상태 타임라인, 결과물 다운로드, 수정요청, 컨펌 버튼

### 7. 로그인/회원가입 (`/login`, `/signup`)
- 이메일/비밀번호 + 소셜 로그인 UI

## 관리자 백엔드 페이지

### 8. 관리자 대시보드 (`/admin`)
- 사이드바 네비게이션
- 통계 카드 (주문 수, 매출, 진행중 프로젝트)

### 9. 서비스 관리 (`/admin/services`)
- 서비스 CRUD 테이블

### 10. 주문/프로젝트 관리 (`/admin/projects`)
- 프로젝트 목록 + 상태 변경
- 결과물 업로드 기능
- 고객 컨펌 상태 확인

### 11. 채팅 관리 (`/admin/chat`)
- 고객 채팅방 목록 & 응답

## 구현 순서
1단계: 공통 레이아웃 (헤더, 푸터, 네비게이션) + 홈페이지
2단계: 카테고리 목록 + 서비스 상세 페이지
3단계: 채팅, 주문, 프로젝트 관리 (고객용)
4단계: 관리자 대시보드 및 관리 페이지
